# Leo Club Chandigarh Fortune

A streamlined, responsive website for **Leo Club Chandigarh Fortune**, affiliated with Lions Clubs International. This repository contains the public-facing landing page designed to showcase the club's initiatives, global causes, and provide a direct point of contact for the community.

---

## 🌟 Features

- **Responsive Design:** Fully optimized for desktop, tablet, and mobile viewing.
- **Theme Toggle:** Built-in Light and Dark mode switching for an accessible user experience.
- **Project Showcase:** Dynamic UI filtering to view 'All' and 'Upcoming' service projects.
- **Global Causes:** Visual highlights of the 8 global causes supported by Lions Clubs International.
- **Reach Out Form:** A comprehensive contact form for prospective members, partners, and general inquiries to connect with the club.

---

## 🛠️ Tech Stack

- **Framework:** [React 18](https://react.dev/)
- **Build Tool:** [Vite](https://vitejs.dev/)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/) & Custom CSS
- **Icons:** [Lucide React](https://lucide.dev/)
- **Typography:** Strictly adheres to the official Lions Clubs International Brand Guidelines (Helvetica Neue & Adobe Caslon Pro).
